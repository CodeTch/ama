## 已修复问题

| 问题 | 修复与证据 |
| --- | --- |
| 按钮、页签等使用 `transition: all`，状态变化可能插值布局和字体 | 改为明确的颜色、背景色、边框色及阴影过渡；全部 585 处定义的计算样式检查通过 |
| 弹窗、抽屉和弹层进场缩放、位移、透明度动画 | 去除共用的缩放、滑入和淡入声明；正常动画偏好下检查弹层动画与按钮位置 |
| 导入弹窗状态变化重建底部操作区，导致焦点丢失 | 移除根据提示和状态拼接的 `key`；回归确认原按钮节点仍连接且保持焦点 |
| 发布、反馈、专题恢复、模板、转写查找等文案切换改变按钮宽度 | 共用 `StableLabel` 按最大候选文案占位，隐藏占位文本不参与可访问名称；包含发布缩窄 28px、反馈横移 39px 等先失败再通过记录 |
| 播放倍速改变按钮宽度并挤动进度条 | 为 1x、1.25x、1.5x、2x 共同占位；使用经过 SHA-256 核对的测试 WAV 实际切换倍速，按钮和进度条保持原尺寸与位置 |
| 反馈、会议库及已发布工作台加载用户资料时，工具按钮横移约 46px | 固定用户区宽度并约束长文本溢出；延迟目录响应验证相邻按钮坐标稳定 |
| 勾选会议插入批量工具栏，将表格下推 69px | 改为固定底部操作栏并预留底部滚动空间；选择与取消选择前后原会议行保持原位置 |
| 同一页重新读取专题时，按钮名称先变成加载文案再恢复 | 保留同账号、仍在当前结果中的已核实名称；身份、范围、移出当前结果或请求失败时清除；403 用例验证旧名称不残留 |
| 演示转写刷新后，历史入口下移约 32px | 为刷新状态预留高度；两条转写演示路径均有坐标回归 |
| 创建会议的状态提示插在按钮上方，造成按钮纵向移动 | 状态提示放在操作区之后，候选文案预留宽度；创建到已受理状态的位置检查通过 |
| AI 纪要核心要素编辑按钮未定位到所属段落，出现在 y=4px 并被顶栏遮挡 | 段落建立定位容器并为编辑按钮保留文字空间；按钮边界位于所属段落内，悬停不位移，可点击打开编辑窗口；两视口完整纪要按钮遍历通过 |
