# CAS 登录实装与联调记录

日期：2026-10-30。范围是 AMA 的企业 CAS 登录、会话签发、退出撤销、前端入口和 `ama-integration-harness` 的 CAS 联调。当前工作树未提交、未合并、未推送。

## 实装

- AMA 增加服务端 CAS 2.0 客户端，固定使用 `/cas/p3/serviceValidate`，严格校验 `ST-*` ticket、service URL、回调路径和 CAS XML namespace。
- CAS XML 解析限制为 64 KiB，关闭 DTD、外部实体、XInclude 和外部 DTD；成功响应必须只有一个用户和不重复的属性，解析失败按 provider 不可用处理。
- CAS 回调只在服务端验证通过后调用共享身份会话签发器。签发仍锁定企业身份、复用 session generation、写入审计，并使用 `Secure; HttpOnly; SameSite=Lax` 的 `__Host-AMA_SESSION`。
- CAS 退出先撤销当前 AMA 会话，再跳转 CAS logout；回调清理本地 cookie。旧的本地开发登录入口在 `cas.enabled=true` 时不再注册。
- Vite 开发代理同时转发 `/api` 和 `/auth`，本地启动器默认启用 CAS，并生成当前前端地址对应的 callback/logout service URL。生产配置必须设置 `CAS_ENABLED=true`、`CAS_ORIGIN`、`CAS_SERVICE_URL` 和 `CAS_LOGOUT_SERVICE_URL`。
- 前端首页的登录、开始录音、导入会议和用户菜单均使用 CAS 入口；不再从产品界面进入本地直签页面。
- 新增 `/login` 生产登录页，按 Omni 目标页复刻招商基金品牌栏、Logo、橙色渐变、卡片尺寸、字段间距、密码显隐按钮、错误状态和响应式断点；页面文案只保留企业账号登录场景，不显示开发环境提示。
- 登录页通过原生表单导航保留 CAS 303 callback，避免浏览器 `fetch(..., redirect: "manual")` 把跨重定向响应变成 opaque response。

## harness 联调修正

`ama-integration-harness` 保留原有 CAS 2.0 XML 接口，同时补充了真实部署场景需要的两个约束：

- `CAS_ALLOWED_SERVICES` 可配置完整 callback URL 白名单，拒绝未注册 service，避免模拟器变成开放重定向器。
- ticket 校验改为带 `used=0`、未过期和 service 匹配条件的数据库更新；并发校验只有一个请求可以成功消费同一 ticket。
- harness 初始化本地联调账号 `dev-owner`、`dev-member`、`dev-viewer`、`dev-admin`，密码均为 `dev-password`，只用于本地联调。

材料读取兼容接口和固定版本响应仍保留在兄弟项目中；它们与本次 CAS 接口分开，未把兄弟项目当作 AMA 业务实现的绝对标准。

## 已验证

- AMA Java：`CasProtocolTest` 3/3 通过，包含 namespace/属性解析、provider failure、XXE 拒绝、缺失用户和重复成功响应拒绝。
- harness：CAS、服务白名单、并发单次消费和材料兼容定向测试 4/4 通过。
- AMA 前端：typecheck 通过，321 个 web 单元测试通过，生产构建通过，OpenAPI 校验和生成类型字节一致检查通过。
- 真实浏览器：未登录页面跳转 harness CAS；`dev-owner` 登录后 `/api/v1/session` 为 200 且 actor 为 `dev-owner`；经 AMA CAS logout 后 session 为 401；无效 ticket 为 401；无 page error。
- 登录页浏览器回归：`/login` 的品牌、标题、企业文案、无开发环境字样、Logo 和卡片结构检查通过；提交真实 CAS 账号后进入 `/meetings`，退出后 session 为 401。
- harness 全新数据目录的 live E2E 为 67/67 通过，包含 CAS redirect/XML/单次 ticket、模型、目录、知识库、文件和邮件接口。

本地联调服务当前可复用：harness `127.0.0.1:8792`，AMA Web `127.0.0.1:5174`，API `127.0.0.1:8182`。本地启动命令和环境变量见 [本地开发说明](../../development/local-development.md)。
