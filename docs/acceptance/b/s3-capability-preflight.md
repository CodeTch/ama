# S3 候选兼容性预检记录

日期：2026-10-22。范围：数据库之外的受控协议调查；**SeaweedFS 4.02 当前测试配置未通过不可变对象创建要求，不能启用为已合格后端**。这不是 B-04 适配器验收或生产资格结论。

候选镜像 `chrislusf/seaweedfs:4.02`，实际版本 `4.02 805950b40 linux amd64`，固定 image SHA256 `3e2b2f87440df5dfb4258075c82a7132d9e95c76a5ea48e8280d2b1d0da0c0cd`。独立工作树 `phase-b-s3-preflight`，BASE `9a6d405`；没有修改产品代码、数据库或公司平台。仅两个任务所有的 loopback 容器曾运行，均已验证所有权后停止并删除，数据保留；凭证没有归档。

|实际协议检查|观察|实现影响|
|---|---|---|
|未启用版本的条件 PUT|串行重放 412；10 次双写竞争均两端 200|条件头不具备所需的原子不可覆盖语义|
|条件 multipart complete|10 次双会话竞争中9次两端200|不能据单次412认定安全发布|
|已启用版本的 PUT/complete|已有对象上条件写仍200并切换当前版本|VersionId作为溯源信息不能修复仅按key读取的不可变契约|
|错误 SHA256 头|PUT及UploadPart都实际接受200|适配器必须验证实际流大小/哈希，不信任用户metadata或ETag|
|响应丢失|代理看到上游PUT/complete200、abort204后截断响应；客户端确实无响应|结果未知须查原key/session和实际内容，不直接认定无效果重发|
|multipart与Range边界|短非末part完成400；乱序manifest被接受；越界Range会截短|需要应用冻结校验清单、映射S3传输part约束、验证精确范围|

原始具名操作244条、signed requests282条，诊断检查40项中15通过、25失败；这些是协议事实，不计为业务测试或负载验收。首次环境代理502及volume容量错误单独保留，未归为产品能力失败。全部来源、经过脱敏的日志、响应丢失代理、固定客户端依赖和完整原报告已保存在 `artifacts/phase-b/s3-seaweed-4.02/`；`manifest.json`逐项记录SHA256，规范 `evidence/probe.jsonl` SHA256为 `7d55c8c41a1a1551dccc0303438c7b20609e586ddc837a35c681e2961eafc345`。

保持 key-only 不可变对象契约；不以HEAD后写、单进程锁、版本开启或忽略失败断言绕过上述反例。其他明确版本/配置须重新独立选择并执行同类真实探测；企业平台同样需要资格证明。当前正在调查其他受控参考实现，尚未采用生产产品。B-04 的 S3 适配器、共同真实后端契约和文件登记仍未完成。

S3普通part的最小传输粒度与通用端口任意逻辑part不等价；后续需显式评审采用协商且持久化的传输part大小，或独立暂存后归并，并验证重启恢复，不对产品文件大小擅加限制。最终发布前必须验证实际总字节/哈希；元数据仅可作可核验声明。磁盘flush、断电、HA、RHEL、DRBD、fencing和负载不在本预检证明范围内。

后续受控参考实现探测已单独完成，见 [RustFS 1.0.3 记录](s3-rustfs-capability-preflight.md)。本页 SeaweedFS 4.02 的失败结果与原始证据不变。
