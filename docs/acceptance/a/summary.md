# 阶段 A 验收与移交

日期：2026-10-21。范围：已批准架构 v0.2 的 A-01…A-05 工程与验证工具。业务数据使用 MySQL；数据库来源与 local/S3 文件后端独立选择。部署目标仍为两台 RHEL 8.10 x86_64、每台 16 核 32GB 的虚拟机。

本阶段交付可启动 API、原型对齐的前端外壳、契约台账、模型诊断探针和 HA 离线预检。录音、导入、转写编辑、纪要和发布业务闭环尚未实现。真实模型容量、公司联调和自动恢复均未验收，不能据本阶段结果声称已满足 100 场实时转写或 300 人在线。

## 本地运行

在本分支的 Linux/WSL 仓库根目录执行。工具下载到忽略的 `.tools/`，不修改系统 Java/Node。

```sh
python3 tools/bootstrap.py
. .tools/env.sh
npm ci --ignore-scripts
npm --prefix web ci --ignore-scripts
npm --prefix web exec playwright install chromium
python3 tools/checks/run.py all
./mvnw -B -ntp package
java -jar backend/api/target/ama-api-0.1.0-SNAPSHOT-exec.jar
```

另一个终端执行：

```sh
. .tools/env.sh
npm --prefix web run dev -- --host 127.0.0.1
```

前端打开终端显示的本地地址 `/meetings`。公司登录尚未接入，页面应明确显示未连接状态。后端详情见 [backend/README.md](../../../backend/README.md)。管理监听默认 `127.0.0.1:8081`；缺少数据库时 live 为 200、ready 为 503。管理接口不得通过公开入口代理。
