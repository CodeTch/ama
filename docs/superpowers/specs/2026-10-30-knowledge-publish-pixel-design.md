# 知识库发布界面像素复刻设计

## 目标

把原型中的“知识库发布”第 5 步复刻到现有 Vue 会议工作台：保持顶部导航、会议标题区、五步流程、页面背景、卡片尺寸、边框、字号、颜色、底部固定操作栏和发布状态反馈与原型一致。页面用于验证“选择知识库/文件夹、预览确认版纪要、执行发布、查看发布结果”的完整交互。

## 范围与约束

- 复用现有 `MeetingDetail`、`MeetingProgress`、`PublicationPanel`、全局 token 和图标组件，不增加另一套工作台壳层。
- 视觉目标是原型的知识库发布页；不延伸到纪要编辑、会议确认、会议列表或其他导航页面的改版。
- 开发验证使用稳定的本地伪目录、伪纪要和本地发布状态；伪数据限定在演示入口和测试中，正式接口类型、调用边界和生产路径保持纯接口逻辑。
- 支持知识库搜索、库内文件夹选择、发布路径展示、纪要预览、发布中、发布失败重试、发布成功只读结果等原型可见交互。
- 不创建 worktree，不切换分支；所有工作在 `/home/tanren/ama` 的 `main` 分支完成。

## 方案比较

1. 沿用 `/meeting/:id/publish` 工作台，在 `PublicationPanel` 中复刻原型并通过可替换数据源驱动。优点是直接覆盖现有入口、复用发布状态模型和未来接口边界；缺点是需要处理现有异步状态与演示状态的隔离。本次不采用。
2. 新增独立 `/knowledge-publish-demo` 页面。优点是把伪数据和原型交互隔离，现有工作台与接口保持不变，便于像素比对；缺点是页面只用于演示验证，后续接入真实发布流程时需要再迁移布局。采用此方案，因为你要求新增独立演示页。

## 页面结构

页面由会议工作台公共头部、五步流程条和发布主体组成。主体左侧为“选择发布位置”卡片，顶部为知识库搜索和数量提示，下方为可选库列表；右侧上方为“发布配置”卡片，显示发布路径、文档标题、来源会议、证据完整性和权限说明；右侧下方为“确认发布”卡片，提供最终文档预览和发布按钮。底部固定操作栏保留“上一步”和“发布到知识库”。

当未完成最终确认时，主体显示原型的锁定空态并引导回会议确认；选择库后读取文件夹并支持根目录、子目录和搜索；发布操作显示模拟进度，失败保留配置并允许重试，成功显示只读状态和正式文档入口占位。

## 数据与接口边界

演示页只使用组件内的本地响应，不调用产品 API，也不改变 `usePublication` 和 `app.publications`。正式工作台接口函数名、参数和响应类型不改变；演示页的伪数据明确限定在 `/knowledge-publish-demo` 路由和对应测试中，便于后续删除或迁移。

- 运行前端类型检查与构建。
- 使用 Playwright 在 1440×900 和 1024×768 视口检查页面无横向溢出，验证库搜索、文件夹选择、预览、发布失败重试和成功结果。
- 对发布页面做截图比对，重点核对原型中的 56px 顶栏、24px 内容边距、五步条高度、双栏比例、固定底栏和橙色主按钮。
