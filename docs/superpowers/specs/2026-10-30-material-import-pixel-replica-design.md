# 材料导入界面原型可见文案复刻设计

## 意图

材料导入弹窗的主文件拖入区需要与原型网页像素级一致。当前布局、遮罩、按钮、材料区和底部操作已经复刻，唯一可复现的差异是格式说明行额外显示了 `DOC / PDF / PPTX`。

## 目标

- 将主文件拖入区的可见格式说明恢复为原型原文：`视频：MP4 / MOV / M4V / AVI / MKV　文本：TXT / DOCX / SRT / VTT`。
- 保留现有真实上传队列、恢复流程、隐藏文件选择器及其已接入格式能力。
- 通过单元测试固定可见文案与隐藏选择器能力之间的边界。

## 非目标与约束

- 不重做弹窗结构，不新增设计，不接入伪造的成功接口。
- 不修改背景材料的本地上传、知识库选择、移除、重试或状态逻辑。
- 所有改动在 `/home/tanren/ama` 的 `main` 分支完成，不创建 worktree。

## 方案

1. **仅调整可见格式说明（采用）**：修改现有 `UploadImportView.vue` 的一行文案，保持选择器和上传能力不变。该方案与像素复刻目标一致，改动最小，避免影响真实接口逻辑。
2. **收缩文件选择器能力到原型文案**：同步删除 DOC、PDF、PPTX 等格式支持，会回退现有已接入的文档导入能力，与当前功能约束冲突。
3. **重建导入弹窗并改为伪数据页面**：会丢失现有恢复、排序和真实上传状态，不符合仅暂缓接口接入且随后恢复纯净接口逻辑的要求。

## 验收

- 可见文案测试通过，并确认隐藏 `accept` 仍保留 `.doc`、`.pdf`、`.pptx`。
- 运行材料导入相关单元测试、前端 typecheck 和 build。
- 在当前浏览器环境重新对比 1440×900 空态截图，差异不再包含格式说明行。
