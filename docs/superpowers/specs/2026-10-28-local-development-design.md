# 本地前后端联通

用户选择独立本地开发环境，使用开发账号和示例会议。目标是在现有会议页面中完成真实会话登录、会议列表与详情读取、新建会议以及刷新持久化。

采用 Vite 同源 `/api` 代理和专用本地启动器。启动器为此仓库新建带归属标签的 MySQL 容器与持久卷，显式执行现有迁移，在 127.0.0.1:8082 启动 API。开发身份和目录、类别适配器放在 `tools/dev/java`，单独编译加载，不进入生产 JAR；按用户 2026-10-28 的更新要求，本地开发登录不校验密码，任意填写或留空均可，保留现有 Secure/HttpOnly 会话 cookie、服务端权限和 Origin/CSRF 校验。

备选企业 SSO 需要尚未提供的公司协议和凭证；仅配置代理无法产生登录会话。用户已选择本地环境。使用现有 Java/Spring/MySQL/Vue，不改变生产企业身份适配器，也不复用历史测试数据库或提供方。原 8080 服务保持运行。

数据和数据库凭证保存在忽略的 `.tools/local-app/`，只初始化一次，重启不删除或重置。开发账号及示例会议明确标注为本地数据。验证包括任意/空白/省略密码均可登录、未知账号与跨源登录/业务写入拒绝、未登录拒绝、账号隔离、真实浏览器 cookie、会话/列表/详情/新建，以及应用重启后的保留。
