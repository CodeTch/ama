# D05：已发布文档治理、拒读和失效传播

接续阶段 D 主计划。用户已授权单 agent 自主实施至 D 完成；main、无 worktree；外部调试统一经过兄弟 harness 的固定 8792 端口。此处定义的是可审计的受控联调协议，不将其称为公司权威协议。现有运行实例在长测完成前不重启。

## 选定方案

- 继续采用现有受控知识库的 Ed25519 委托和固定 provider/store/client/key 身份，增加版本化治理读/命令协议；harness 透明转发原始签名字节，拒绝增加任意代理目标或改变固定端口。
- 接受撤回/废止时，先在本地持久记录原键、原请求摘要、固定 publication/document/actor/版本及有界理由，并原子将会议标记为对应 pending、推进访问版本/取消栅栏。未知远端结果保持拒读，原键查回与重试不创建第二个命令。
- 远端只允许 ACTIVE → WITHDRAWN 或 OBSOLETE，terminal 不可恢复。命令回执持久、原键稳定；权威状态短期签名并绑定完整资源和单调版本。回调验签、按 eventId 去重、拒绝乱序回活；丢失回调由持久对账补偿。
- 已发布会议的普通读取、下载、检索和材料引用受同一有效性覆盖；权威状态未知或新鲜度过期拒读。长流继续使用每 2 秒续验/最多 5 秒授权窗口。状态历史/任务诊断只返回允许的元数据。
- 最终确认继续沿用既有全来源快照证明；补实际材料/候选/未保存阻断验收，不以治理测试替代最终快照测试。
