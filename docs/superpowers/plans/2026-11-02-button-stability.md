# 全页面按钮稳定性排查计划

**目标：** 逐页检查全部按钮及弹窗、抽屉中的操作，修复点击、加载、状态切换时非预期的布局位移和闪烁。

**约束：** 所有工作在 `/home/tanren/ama` 的 `main` 分支进行；单 agent；不建立工作树，不切分支；保留开始时已有的修改。使用 executing-plans 在当前会话顺序执行，完成后自行复核，不派生审查 agent。

**技术：** Vue 3、Vue Router、Vite、Playwright、Node 单元测试。浏览器使用受控接口数据，不对用户现有会议执行删除、发布等操作。

- 全局录音、删除、发布治理提示；未知路由返回入口；原生播放器与展开控件。

## 重点验证

1. 页签选中、按钮忙碌/禁用不会引发宽度、位置、字体尺寸插值。
2. 同一身份、同一资源的重新读取不会先清空已显示内容；身份、权限、资源变化仍清除旧数据。
3. 弹窗和抽屉打开/关闭不引起背景闪烁或横向移动，键盘焦点仍可见。
4. 短/长标签、窄视口和重试状态不挤动相邻操作。
5. 预期的导航、展开和内容更新与非预期抖动分别记录。

## 执行记录

- 开始时目录和分支已确认；已有修改：`web/index.html`、`web/src/App.vue`、`web/src/features/meetings/MeetingList.vue`、`web/tests/unit/meeting-list-view.test.ts`、`web/tests/e2e/home-refresh.spec.ts`，以及未跟踪的 `data/`、`test-results/`。
- 通过 AST 清点 60 个组件、521 处原生按钮及 64 处其他交互入口，共 585 处定义；额外检查 `main.ts` 的未知路由返回链接与后端正式文档静态页面（后者无按钮）。
- 已记录先失败再通过的实测：发布按钮缩窄 28px、反馈提交横移 39px、工具栏横移约 46px、倍速控件挤动约 17px、转写历史下移约 32px、会议选择表格下移 69px、导入 footer 节点被重建。
- 决策：批量操作使用固定底部栏，避免在表格上方插入一整行；页面预留底部空间以便滚动到最后一行。
- 决策：专题名称只在同一账号、同一已展示会议的读取期间保留；身份/范围/会议移出以及请求失败时立即清除旧名称，403 回归用例验证不残留旧标签。
- 测试夹具的 CAS 导航拦截由 `**/auth/**` 收窄为 `**/auth/cas/**`，避免误拦 Vite 的认证组件模块；关闭弹层属于预期视图变化，独立于尺寸抖动断言记录。
- 完整遍历发现核心要素编辑按钮因父级缺少定位而被顶栏遮挡（y=4px）；先补失败回归，再将按钮定位到所属段落并预留文字空间，两个视口均通过逐按钮复验。
- 最终证据：591 项单元测试通过；按最新结果合并的 220 项唯一 E2E 通过；130 份场景记录共 1346 次检查（1086 点击、260 禁用）；类型检查、构建及差异格式检查通过。两项原型视觉快照仍为开始时相同的页眉标识差异（各 1380px），未更新基准。
