## 4. 关键问题、根因与修改落点

### F01：首次生成与加载状态没有按 P01 收敛

**证据：运行确认 + 代码确认。** `MinutesWorkspace.vue:113` 在正文为空时显示生成表单，`:116` 又在 current 对象存在时渲染完整工作台；body/set 都为空仍显示目录及局部生成入口。`:115` 初始仅有“正在读取已保存纪要…”；`:70` 先等 actions 再等 editor，两者还会做授权读取。当前客户端不能保证该读取在明确时限内退出等待。

`MeetingDetail.vue:37` 的自动生成意图是内存 `ref(false)`，靠转写确认事件置位；不能从持久任务/输入状态完整恢复确认到首次生成的过程。`:50` 阶段文案主要看正文/转写指针，未区分任务执行与失败。

`MinutesGenerationPanel.vue:29` 仅对本页 command ack 的 taskId 启动轮询，最多约 30 次、间隔 2 秒；从服务端读到 `activeTaskIds` 不会按同一逻辑续查。达到轮询次数后没有完整的持续状态呈现。这里“命令已回执”与“任务执行完”需要拆开。

**修复：** 首次无结果、执行中、失败、已保存工作台互斥呈现；回访按服务端任务恢复；超时与失败给可执行恢复路径；保留原任务幂等键。优化读取调度前测量各请求，不删除现有权限租约及撤权检查来换取加载速度。

### F02：本地总结能力仍为合成输出，模板未按规格安装

**证据：运行确认 + 代码确认。** `tools/dev/local_app.py:426` 启动 `ControlledMinutesProvider`；`tools/dev/local_minutes.py:139` 安装受控配置，默认 prompt 为 `controlled:rich-no-sensitive`。`ControlledMinutesProvider.java:98` 各类条目拼固定英文字符串，`:99` 固定标题/正文，`:107` 局部候选固定拼类别，`:113` 主题内容为 `Controlled synthetic content.`。这能测协议、版本和交互，不能证明按会议内容总结、按局部要求改写或实际敏感识别。

`ControlledMinutesTemplateInstaller.java:15` 安装名为 `Controlled minutes` 的默认模板；真实页面也如此。需求 §6.8 要求 AI生成（默认）、正式会议纪要、简明总结。不能只把显示名改成中文就认定真实模板已完成。

**修复：** 在现有输入版本/来源/输出验证边界接入真实纪要模型能力，三种模板绑定各自真实模板修订。已有 `designDocs/线上模型服务接口文档.md` 主要给出语音处理与文本校正调用，并不足以证明纪要结构化输出契约已经完成；实施先确认真实接口及能力，保留受控 provider 作测试夹具。以上结论限定于本次本地环境和已检查代码，不外推其他部署。

### F03：“已生成”“已应用”“可确认”被一个标记近似表达

**证据：代码确认。** `MinutesSavedWriter.java:26` 的 `advanceEdit` 更新正文/要素指针及确认失效，但不更新 `needs_generation` 或生成指纹；`JdbcMinutesSavedCommands` 的要素、行动等编辑复用此路径。此前标记为 false 时，要素改动不会据此显示需重生成。

另一个方向，`MinutesTaskDomainPolicy.java:67` 完成候选并调用 `firstSave`；已有正文不走首版自动保存。`MinutesSavedWriter.java:21` 在采用时才更新生成标记，而 `MinutesWorkspace.vue:120` 直接用 `observation.needsGeneration` 显示提示。因此当前输入的全文候选成功、尚未采用时，提醒仍存在，与需求模块三 §2/§4 明确规则不符。

### F04：条目操作、行动项和分类语义可达性不足

### F05：敏感信息已有链路，但权限、展示和人工冲突闭环不全

## 6. 必须验收的场景表

| 场景 | 必须观察的行为 |
| --- | --- |
| 未确认转写 | 生成被服务端拒绝，旧稿保留；不能用保存稿绕过确认 |
| 已确认、无设置、无纪要 | 默认 AI生成和空排除，可靠衔接生成；信息可后补 |
| 首次执行/执行失败 | 正确的 P01 状态、依据版本、真实阶段、明确原因及幂等重试 |
| 超过 60 秒、刷新、切页返回 | 任务继续并恢复观察；不重复生成，不只靠本页 ack |
| 首版完成时已开始编辑 | 保护输入，不违反 D-20 自动覆盖 |
| 已有稿全文生成成功未采用 | 旧正文仍当前有效；标题变更提示消失；候选待决定且阻断有效确认 |
| 生成失败、成功后再次改设置 | 失败保留提醒；再次变更重现提醒，旧候选不能覆盖 |
| 改要素/行动、局部采用 | 正文待更新；其他区域和人工正文不被覆盖 |
| 缺来源/负责人/日期 | 明确依据不足；字段可核对；不猜身份，不强制日期、不授权新成员 |
| 两类敏感、全部/部分排除 | 设置保存、未应用提示、真实生成应用、原音文不变 |
| 人工重新加入排除内容 | 有冲突检测/反馈及最终确认处理，记录实证能力边界 |
| 模板不可用/新建/切换 | 无静默替换；个人可见；选中不等于正文已应用 |
| 编辑与保存失败/冲突 | 草稿保留，刷新恢复，离开选择正确；复制草稿、导出已保存版本 |
| 两版本比较/完整恢复 | 五类真实差异、完整关联、新修订、确认失效、历史不丢 |
| 参会人/被移除成员 | 有权读取有效成果与敏感摘录；无编辑入口且 API 拒绝写入；撤权及时生效 |
| 原文失效/源库无权 | 明确不可读，不伪造摘录，不扩大源授权 |
| 已发布/撤回后 | 固定发布快照及治理规则，不能通过草稿/历史接口绕过 |
| 1440×900、1024×768 | 核心、正文、首次、敏感、来源、编辑、候选、历史各状态有独立视觉证据 |
