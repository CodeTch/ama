## Actionable finding

### T9DR-01 — P2 — Freeze the minutes HTTP contract in the existing versioned namespace and actual contract tree

**Location:** `task-09-minutes-generation-design.md:258` (route family at 258–266; also 122 and 156); contract output location at line37 under the table explicitly headed “Path under backend”.

**Failure:** Task9 freezes every generation/catalog/initial-settings/input/task/candidate path as `/api/meetings/...`, while actual `backend/api/src/main/java/ama/api/MeetingController.java:30` and `contracts/openapi/api.yaml:22` establish `/api/v1/meetings`; adopted Task6 R1 line225 and Task10 line196 also freeze the latter prefix. There is no specified compatibility/version transition or dual-route policy. A consuming Task12 client built against the existing/adjoining base path will request a different endpoint from the one this producer design tells its controller author to install. Independently, line37 directs the producer OpenAPI file into `backend/contracts/openapi`, whereas the existing API aggregate and referenced contract files are in the repository-root `contracts/openapi` tree. Implementing that table literally leaves the new schema outside the actual aggregate/generation path. These are concrete source/contract contradictions at a gate whose purpose is to settle exact producer paths before UI consumption; the general final-facade gate does not settle them.

This is **not** an authentication-bypass finding: actual security registration matches `/api/**`, and Task9 explicitly requires the shared session/CSRF/Origin/B03 checks. Severity is P2 because it is a small contract-integration defect, not a demonstrated loss of confidentiality or persisted data.

**Smallest correction:** change all Task9 product routes and examples to `/api/v1/meetings/{meetingId}/minutes/...`; identify the file as repository-root `contracts/openapi/minutes.yaml` (outside the backend-only path table, or explicitly qualified), and state that the designated contract owner adds those paths/refs to the existing root `contracts/openapi/api.yaml` before Task12 client generation. Keep the controlled provider's separate `/v1/minutes/...` protocol unchanged. A bounded design delta and exact route/path cross-check suffice for this finding; no runtime test claim follows from that correction.
