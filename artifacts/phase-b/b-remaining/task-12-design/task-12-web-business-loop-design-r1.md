## 4. Transport, security, versions and state

Explicit controlled harness can renew its fixture session; production shows unavailable enterprise sign-in. 403 is not automatically retried with another actor. New session identity must not reveal a previous actor's draft.

Use opaque canonical decimal strings for every browser-used revision/access/publication/history/intent/offset counter. New mutations send only `expectedRevisionToken` and actual corresponding token fields. No Number/parseInt, arithmetic or token derived from legacy numeric JSON. Numeric duplicates may be present for compatibility but are ignored for CAS. Server normalizes legacy/token/equal-dual forms to the same exact integer before the old semantic digest. Token grammar/range is server-owned; client preserves exact token. Display order uses supplied order or explicitly bounded display values, not unsafe subtraction. Unicode evidence offsets are scalar positions: editor selection conversion counts code points with a tested adapter, validates surrogate correctness, and sends decimal offsets; JS UTF16 offsets are not source offsets. This conversion is not revision arithmetic.

`useCommand` freezes operation/actor/resource/key/body/base tokens before first send; one request per command, disable duplicate submit, hold exact request on unknown network/503/lost response. A semantic edit creates a new command only after unresolved prior acceptance is reconciled; it does not mutate that command's body/key. Retry sends exact original body/key. ACK and current observation are separate: an accepted historical task/result remains accepted if fresh readiness lookup fails or now points elsewhere. Intent has its explicit stale expected-revision replay rule. Preserve local draft on 409, fetch current saved into a separate conflict pane; never silently replace its base token and retry as an overwrite. User can inspect/copy/discard/reapply their changes against freshly loaded state; new intentional command uses current base, new key and fresh eligibility. No automatic merge of scalar anchors or action tuples.

Error parsing accepts only bounded declared BusinessError envelope/allowlisted code and safe trace ID. Render local messages, not arbitrary backend message/HTML/stack/cause. Known 400 invalid request, 401 session, 403 forbidden, authorized404 missing, 409 conflict, 413 bounded size, 422 unsupported input, 503 unavailable map to specific repair actions. Retry button appears only for the applicable server action; raw code/state strings cannot authorize writes. No fetch fallback to provider URLs, storage routes/keys or management endpoints.

### Tab-specific edit-intent state machine
