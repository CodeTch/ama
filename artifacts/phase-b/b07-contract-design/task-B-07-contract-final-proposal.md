## 1. S1 boundary and exact types

S1 implements only defensive immutable types, canonical encoding/hashing, strict JSON parsing/structural validation, deterministic source aliases/anchors and conservative creation classification. Caller supplies detached immutable input facts; no DB/file resolver, HTTP/model call, Spring registration, task/ACL handler, config activation, persistence, human attestation, candidate adoption or finalization. Unknown production capability stays unavailable.
[A] Exactly seven keys/kinds: OVERVIEW 会议概述; DISCUSSION 核心讨论; CONCLUSION 关键结论; ACTION 行动项; RISK 风险事项; OPEN_QUESTION 待确认项; DISAGREEMENT 未达成一致事项. Sensitive/background/related materials are separate directories; no eighth subject kind, no discarded kind from visual grouping. Empty category means empty array/no fake NOT_EXTRACTED row.
All object fields below are required; union alternatives have exactly their listed fields; unknown/duplicate keys fail, null only where explicitly allowed. Object key order is immaterial, list order material unless explicitly a set. No missing→default, trimming, normalization, coercion, repair or unknown-field dropping. Internal records defensively copy lists/maps and reject null members outside nullable fields.

LocalKey=`[A-Za-z][A-Za-z0-9_-]{0,63}` ASCII, globally unique across Element/Detection/Note entries, response-local not persisted UUID. Alias=`s` followed by unpadded positive decimal long, e.g. s1/s2; this replaces original fixed 8-digit alias width, avoiding a separate count ceiling. Alias identity scoped to inputFingerprint; parse ordinal exactly, no case/zero/space variation. Hash=`[0-9a-f]{64}`. UUID is lowercase exact `[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}`, excluding all-zero; syntax never proves membership/permission.
UInt is raw JSON integer lexeme `0|[1-9][0-9]*`, exact value 0..9223372036854775807, never floating point; positive indices additionally >0. Reject -0/negative/sign/fraction/exponent/quoted/boolean/overflow/NaN/Infinity. Protocol long bounds are technical, not product count limits. Date is exact ASCII YYYY-MM-DD, strict Gregorian validation, range 1000-01-01..9999-12-31; suggested date stays unverified, absent/ambiguous date null.
Text is strict Unicode scalar text, allows HT/LF but rejects other U+0000..001F and U+007F; supplementary pairs allowed, lone surrogates rejected. Nonblank has at least one scalar outside fixed White_Space set {0009..000D,0020,0085,00A0,1680,2000..200A,2028,2029,202F,205F,3000}. Title may be empty (suggestion only); body/nonblank entries may not. This restriction is MODEL OUTPUT only; accepted B06 source/hash strings retain exact saved scalars/controls, no cleanup or text rewrite.
SensitiveKind [A] = INTERNAL_BUSINESS_DATA or POLITICAL_SENSITIVE; both labels at one location remain distinct entries. ACTION requires Action; other kinds require action:null. Owner mention is raw content, never enterprise identity. Every generated ACTION gets action_suggestion even when both fields null; accepted action_item owner_enterprise_id/owner_display/due_on all initially NULL. No automatic owner/date mapping.
AliasSet is nonempty, no duplicate alias; its order is ignored after validation and canonicalized by numeric catalog ordinal. Repeated equivalent locator IDs in one membership set fail, not silently merged. Output Ref aliases must be unique and exactly the aliases used by evidence/detections/notes; unused/dangling Ref fails. Distinct directory entries remain distinct even if source sets/text are identical. Exact duplicate Evidence target+alias membership pair fails; overlapping different target ranges remain legal.

## 4. Shared CanonicalValueCodec and domain hash profiles [P]

`ama.canonical-value.v1` is a typed binary codec, not JSON canonicalization or Jackson-dependent serialization. Values are Null, Boolean, UInt(long>=0), ScalarString, List, Object(ordered input Entry list, each string key→value). The Object constructor rejects duplicate keys before any map conversion and freezes entries; encoding then sorts them. No floating point/decimal/date/UUID implicit conversion. Strings are all Unicode scalar sequences including exact saved control characters; reject malformed UTF-16 before strict UTF8 encode, no replacement/NFC/line-ending change. Dates/UUID/hash/enums enter as schema-validated canonical strings; UTC timestamps use exact `YYYY-MM-DDTHH:mm:ss.ffffffZ` with truncation done by writer before snapshot, not by codec.
Encoding: Null=00; false=01; true=02; UInt=03||u64be(value); String=04||u64be(UTF8 byte count)||bytes; List=05||u64be(count)||Encode(each); Object=06||u64be(field count)||Encode(key)||Encode(value)... with keys sorted lexicographically by unsigned strict UTF8 bytes. No BOM/header beyond tag, no separators or omitted values. u64be is 8 bytes; supported lengths/counts/values remain 0..Long.MAX_VALUE. Every object schema field is present; null distinct from empty string/list/object and tagged EMPTY. No set type: schema sorts set members before constructing List; codec never sorts ordinary lists.
CanonicalBudget={maxEncodedBytes:long,maxDepth:int,maxNodes:long,maxStringBytes:long,maxContainerEntries:long}, all >0, exact checked arithmetic. Preflight entire immutable tree for strings/duplicate object keys/depth/nodes/lengths, then bounded encode/hash; no partially successful return. `encode` returning byte[] also requires computed bytes<=Integer.MAX_VALUE; `sha256` may stream to digest within maxEncodedBytes without whole-output copy. Caller budget controls both. Reject object duplicate decoded keys at construction, even if map conversion would discard one. Cancellation/interruption checks apply to scans/sorts/encoding; no silent success after cancellation.
Domain digest is always `lowerHex(SHA256(Encode({profile:ProfileVersion,kind:Domain,data:TypedData})))`; no string concatenation of unescaped IDs. Exact Domain values: GENERATION_INPUT, TRANSCRIPT_CONFIRMATION, ROWSET, REVIEW_TARGET, REVIEW_SOURCES, FINAL_SOURCES. Profiles below resolve archived immutable definitions; use distinct profile literal per incompatible schema, no latest/default. Generic primitive golden vectors below hash raw Encode only, explicitly not domain digests.
